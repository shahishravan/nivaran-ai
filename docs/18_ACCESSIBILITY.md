# Accessibility

## Interaction
All important actions should be reachable by keyboard and use native button, input, dialog, tab, and heading semantics.

## Visual
Text and status indicators require sufficient contrast in light and dark themes. Risk must not be communicated by color alone.

## Content
Buttons use action-oriented labels. Confidence, status, SLA, and evidence are presented in text. Synthetic metrics are clearly labeled.

## Motion
Progress animations must not block input or conceal the final state. A reduced-motion mode is a production requirement.

## Verification
Test keyboard order, visible focus, screen-reader names, zoom at 200%, narrow viewports, and common color-vision conditions before production release.
