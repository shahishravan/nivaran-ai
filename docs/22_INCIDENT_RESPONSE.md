# Incident Response

## Incident types
Unauthorized action, sensitive-data exposure, incorrect safety classification, duplicate financial action, unavailable recovery workflow, or tampered evidence.

## Immediate response
1. Stop affected write tools.
2. Preserve logs and approval records.
3. Identify impacted tenant and cases.
4. Notify the responsible owner.
5. Revoke or rotate exposed credentials.
6. Correct customer-facing harm through an authorized process.
7. Document root cause and preventive action.

## AI-specific review
Separate model error, harness error, policy error, tool error, data-quality error, and human-approval error.

## Recovery
Restore service from a verified version and confirm that blocked actions, idempotency, evidence, and audit controls work before re-enabling automation.
