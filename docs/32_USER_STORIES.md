# User Stories

## Business owner
As an owner, I want critical reviews surfaced first so I can act before customer and reputation harm compounds.

## Operations manager
As an operations manager, I want every recovery case to include a corrective task so the same failure is less likely to repeat.

## Support lead
As a support lead, I want contextual drafts and visible evidence so I can respond quickly without surrendering judgment.

## Approver
As an approver, I want consequential actions paused until I review them.

## Analyst
As an analyst, I want recurring issue patterns connected to recovery outcomes rather than sentiment counts alone.

## Judge
As a judge, I want a reproducible synthetic scenario, visible limitations, inspectable agent trace, and clear distinction between prototype and production.
