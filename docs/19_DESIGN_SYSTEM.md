# Design System

## Product character
Nivaran uses an operational command-center visual language: dark surfaces, clear hierarchy, compact evidence, status contrast, and deliberate motion.

## Semantic colors
- Red: critical unresolved risk
- Amber: attention or waiting
- Green: verified or complete
- Blue: analysis and system context
- Neutral: supporting metadata

Color is always paired with text or iconography.

## Component rules
Cards show one decision level. Metrics include a label and context. Primary buttons advance the current mission; secondary buttons inspect evidence or alternatives.

## Typography
Headlines communicate outcomes. Body copy explains evidence and boundaries. Monospace text is reserved for identifiers, policies, and structured traces.
