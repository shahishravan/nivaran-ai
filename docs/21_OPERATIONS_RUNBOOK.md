# Operations Runbook

## Before a demonstration
1. Open the public URL in an incognito window.
2. Sign in with judge credentials.
3. Confirm synthetic data is loaded.
4. Run Recovery Command once.
5. Open Decision Lab, Recovery Control, Evaluation Lab, and Agent System.
6. Confirm dark mode and 100% zoom.
7. Close unrelated tabs and notifications.

## If the app fails
- Confirm network connectivity and public deployment status.
- Retry in a clean private window.
- Use the last verified deployment rather than changing code during recording.
- Do not expose platform dashboards or private workspace URLs.

## After submission
Save confirmation screenshots, submitted URLs, deployed commit SHA, and video permission state.
