# Recovery Receipt

A recovery receipt is the proof artifact created after a case reaches a verified outcome.

## Contents
- Incident and source reference
- Prioritization evidence
- Selected recovery path
- Human approver
- Customer action reference
- Corrective-task reference
- Outcome evidence
- Completion timestamp
- Policy and model versions

## Closure rule
A draft, queued response, or closed ticket is insufficient. The receipt remains unsealed until customer and operational evidence is present.

The demo receipt is synthetic. Production receipts should be append-only, access-controlled, privacy-minimized, and exportable for internal review.
