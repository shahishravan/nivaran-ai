# Data Flow

## Recovery path
1. A review enters from the synthetic inbox, manual entry, or CSV demo import.
2. Signal analysis produces sentiment, intent, topic, risk evidence, urgency, and confidence.
3. Recovery planning matches evidence to a policy-aware intervention.
4. Decision Lab compares likely consequences.
5. The owner approves customer and operational actions.
6. Recovery Control assigns an owner, SLA, customer action, and corrective task.
7. Resolution evidence is recorded.
8. A recovery receipt is sealed only when evidence is complete.

## Trust boundaries
Customer text is untrusted input. Generated drafts are proposals, not published actions. Human approval is required for consequential actions.

## Data minimization
The demonstration contains no private records, API keys, order identifiers, phone numbers, or payment data.
